# ER-diagram
## Feladat – Iskolai nyilvántartás

Egy iskola adatbázisában tanárokat, diákokat és osztályokat szeretnénk nyilvántartani. Minden tanárról és diákról tároljuk a személyi azonosítóját, a nevét, a lakcímét és a születési dátumát. A személyi azonosító egyértelműen azonosít minden embert.

Minden osztályról tároljuk az osztály nevét és létszámát. Az osztály neve az iskolán belül egyedi. Minden diák pontosan egy osztályba járhat, egy osztályba viszont több diák is tartozhat. Minden osztálynak pontosan egy osztályfőnöke van, aki tanár, egy tanár pedig legfeljebb egy osztály osztályfőnöke lehet. A tanárok több osztályt is taníthatnak, és egy osztályt több tanár is taníthat.

**Feladatok:**

a) Tervezd meg a feladatnak megfelelő ER-modellt, és válaszd meg a kulcsokat!

b) Jelöld az egyedtípusok közötti kapcsolatokat, és add meg azok számosságát!
